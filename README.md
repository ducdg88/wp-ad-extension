# WP Auto Ad Inserter

**Finish a post in WordPress → click one button and your ad code lands in the right spots.**

**Viết xong bài trong WordPress → bấm một nút, mã quảng cáo tự chèn đúng chỗ.**

**Finish writing a WordPress post → click one button, the ad code inserts itself in the right spot.**

**WP Auto Ad Inserter** is a Chrome extension that automatically inserts ad code into posts in the WordPress editor (Gutenberg/Classic Editor).

**WP Auto Ad Inserter** là một tiện ích mở rộng trình duyệt (Chrome Extension) giúp tự động chèn mã quảng cáo vào bài viết trong trình soạn thảo WordPress (Gutenberg/Classic Editor).

## 🚀 Features · Tính năng chính
- Detects the post content automatically. · Tự động nhận diện nội dung bài viết.
- Inserts ads at custom positions (top, middle, end of post). · Chèn quảng cáo vào các vị trí tùy chỉnh (đầu bài, giữa bài, cuối bài).
- Supports many types of ad code. · Hỗ trợ nhiều loại mã quảng cáo khác nhau.
- Simple, easy-to-use management UI. · Giao diện quản lý đơn giản, dễ sử dụng.

## 🛠 Install · Cài đặt
1. Download the source code. · Tải source code về máy.
2. Open Chrome and go to `chrome://extensions/`. · Mở trình duyệt Chrome, truy cập `chrome://extensions/`.
3. Turn on **Developer mode**. · Bật **Developer mode**.
4. Click **Load unpacked** and select the source code folder. · Chọn **Load unpacked** và chọn thư mục chứa source code.
